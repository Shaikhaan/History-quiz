# History Quest - Interactive Learning

An engaging history quiz application that takes users on an epic journey through different civilizations and historical eras.

## 🏛️ Features

- **5 Civilizations**: England, France, Italy, Japan, and Ottoman Empire
- **25 Levels**: 5 difficulty levels per civilization
- **Interactive Learning**: Read historical content before taking quizzes
- **Achievement System**: Earn badges and track progress
- **Responsive Design**: Works on desktop and mobile devices
- **Progress Tracking**: Local storage saves your achievements

## 🎮 How to Play

1. **Choose Your Empire**: Select from 5 historical civilizations
2. **Pick Your Era**: Choose from 5 difficulty levels (Novice to Master)
3. **Learn**: Read the historical chronicle for that era
4. **Test**: Take a quiz to test your knowledge
5. **Achieve**: Earn points, badges, and unlock new content

## 🏆 Badge System

- **Performance Badges**: Perfectionist, Scholar, History Expert
- **Civilization Masters**: Complete all levels for each empire
- **Special Achievements**: Lightning Scholar, Dedicated Learner, Unstoppable

## 🚀 Getting Started

### Option 1: Simple File Opening
1. Download or clone this repository
2. Open `index.html` in your web browser
3. Start your historical journey!

### Option 2: Local Server (Recommended)
```bash
# Navigate to the project directory
cd history-quiz

# Start a local server (Python)
python -m http.server 8000

# Or using Node.js
npx serve .

# Open http://localhost:8000 in your browser
```
